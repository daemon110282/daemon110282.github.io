## Зачем

- __UX__-[дизайн](https://practicum.yandex.ru/blog/chto-takoe-ux-ui-dizayn/) (User Experience — «пользовательский опыт») отвечает за то, __как интерфейс продукта работает__
  - Usability - цель создать продукт, которым легко пользоваться
- __UI__-дизайн (User Interface — «пользовательский интерфейс») отвечает за то, __как интерфейс выглядит__

Включает:

- __[Дизайн-система](#дизайн-система)__ — это вообще вся информация по дизайну проекта
- __[UI-kit](#ui-kit)__ — это набор __компонентов__, из которых собирается интерфейс

## Дизайн система

__Дизайн система__ - это набор готовых элементов, стандартов, инструментов и процессов, которые:

- входит __редполитика__
- ускоряют проектирование продуктов и упрощают разработку
- создают консистентный пользовательский опыт цифровых продуктов
- задают высокую планку дизайна и разработки интерфейсов

Примеры:

- Paradigm
- дизайн-система VK
- [РосТелеком](https://design.rt.ru/preview)
- [Контур](https://guides.kontur.ru/)

## UI Kit

Используется только на этапе реализации интерфейса.

[Включает](https://practicum.yandex.ru/blog/ui-kit-chto-eto-i-zachem-nuzhen/):

- Типографика
- Цвета
  - Темная тема
- Модульная сетка и система отступов
- Основные элементы управления
  - Кнопки и контроллеры
- Основные элементы навигации
- Попап-элементы
- Индикаторы прогресса
- Иконки
- Эффекты
- Дополнительные элементы. Например, шаблоны экранов, блоков и отдельных страниц, логотипы, виджеты, анимация, фотографии и иллюстрации.

Примеры:

- Figma Community
- Behance
- Dribbble
- КОД
- [Газпром](https://consta.design/)
- [Госуслуги](https://guides.gosuslugi.ru/)
- [Тинькофф](https://www.figma.com/community/file/1220308188005380608)
