# Agent Harness Обвязка

## Зачем

Полная [программная инфраструктура](https://habr.com/ru/articles/1023316/), обёртывающая "обвязка" LLM: оркестрационный цикл, инструменты, память, управление контекстом, персистентность состояния, обработка ошибок и ограничения.

## Как работает цикл harness

Цикл состоит из нескольких шагов:

- харнесс __собирает промпт__ — объединяет системный промпт, схемы инструментов, файлы памяти, историю диалога и сообщение пользователя;
- промпт отправляется в __LLM__ API — модель генерирует выходные токены;
  - оркестрация и мультиагентность — дорогая модель для верификации и сложного проектирования и раздумывания, средняя для генерации и оркестрации, быстрая и дешёвая для массовых субагентских вызовов.
- харнесс классифицирует вывод модели: если запрошены вызовы инструментов — выполняет их, если нет — завершает цикл;
- результаты инструментов __форматируются__ и добавляются к __истории диалога__;
- при приближении к лимиту контекстного окна харнесс __запускает compaction__ (суммаризацию истории);
- цикл повторяется до завершения задачи.
