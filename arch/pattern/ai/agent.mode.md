# Agent mode

## Зачем

Агенты — ИИ, который не просто пишет код, а самостоятельно планирует и выполняет действия для достижения цели.
В отличие от чата, агент может:

- Анализировать кодовую базу
- Создавать и редактировать файлы
- Запускать команды в терминале
- Исправлять ошибки на основе логов
- Итеративно улучшать решение

## Custom Agent

Custom agent задаёт роль и рабочую среду помощника, а skill — конкретную инструкцию или навык, который помощник подключает для подходящей задачи.

| | Custom agent | Skill |
| --- | --- | --- |
| **Зачем** | Определить, *кто* работает и *как*: роль, инструкции, доступные инструменты, ограничения | Научить выполнять *определённый тип задачи*: дать алгоритм, правила и справочные материалы |
| **Когда применяется** | Вы выбираете агента, например из списка чата | Может подключиться автоматически по запросу или быть вызван явно |
| **Обычно содержит** | Описание роли и поведения, настройки инструментов; файл `.agent.md` | Папку со `SKILL.md`, а также связанные справочники и ресурсы |
| **Пример** | «API-архитектор», который помогает проектировать и проверять контракты | Пошаговая инструкция по проектированию одного REST API-метода |

Они **не заменяют друг друга**: custom agent может использовать один или несколько skills. Например, агент «API-архитектор» задаёт общий стиль работы, а skill уточняет, как спроектировать метод добавления товара в избранное.
