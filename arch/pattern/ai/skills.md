# Skills

## Зачем

[Skills](https://claude.com/resources/articles/skills) нужны, чтобы дать AI не просто "общую" подсказку, а готовый набор правил и контекста для конкретного типа задач.

Если коротко:

- они задают, когда AI должен использоваться;
- что именно нужно учитывать в этом типе работы;
- какие инструменты и подходы предпочтительны;
- как оформлять результат.

Почему это полезно:

- Повторяемость: не нужно каждый раз заново объяснять одно и то же.
- Точность: модель работает в нужном контексте, а не “угадывает”.
- Ограничение ошибок: можно явно запретить лишние действия, указать приоритеты и стандарты.
- Масштабируемость: один и тот же “навык” можно применять к разным задачам в проекте.
- Специализация: для разных областей — разные правила: frontend, backend, security review, docs, tests, data.
- команды могут иметь свои стандарты;
- разные задачи требуют разных подходов;
- можно быстро подключать нужный контекст без лишнего диалога.

## Пример

- Skill “code-review” говорит агенту: проверяй изменения, ищи логические ошибки, не фокусируйся на стиле.
- Skill “security-review” говорит: проверяй уязвимости, обращай внимание на auth, validation, injection, secrets.
- Skill “pdf” говорит: извлекай текст из PDF и структурируй результаты.

То есть skills — это не "магия", а шаблон поведения для AI. Они помогают сделать агента более дисциплинированным и предсказуемым.
