# Test Driven Development (TDD)

## Зачем

- Test Driven Development (TDD) — это подход к разработке программного обеспечения, который ставит __тестирование на первое место__
- Разработчики сначала пишут тесты для новой функциональности, а затем пишут код, который позволит этим тестам пройти
- микро-практика одного разработчика
- цикл __Red-Green-Refactor__
