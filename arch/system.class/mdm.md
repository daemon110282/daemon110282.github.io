# MDM

## Зачем

[Класс систем](system.class.md) MDM (Master Data Management) — для централизованного управления мастер-данными организации: клиентами, контрагентами, продуктами, организациями, сотрудниками и другими ключевыми бизнес-сущностями.

Основная задача MDM — обеспечить единый, достоверный, согласованный и актуальный источник мастер-данных для всех информационных систем предприятия.

## Функции

| Функция | Назначение |
| --- | --- |
| Data Modeling | Определение __модели мастер-данных__, атрибутов, связей и ограничений |
| Data Quality | Проверка полноты, корректности, уникальности и актуальности |
| Matching | __Поиск__ записей, относящихся к одной сущности |
| Deduplication | Обнаружение и обработка __дубликатов__ |
| Golden Record | Формирование __эталонной__ записи сущности |
| Survivorship | Выбор достоверных значений атрибутов из разных источников |
| Hierarchy Management | __Управление иерархиями__ организаций, групп компаний, продуктов |
| Data Governance | Правила __владения данными__, согласования и контроля изменений |
| Data Lineage | __Отслеживание происхождения__ и преобразований данных |
| Data Distribution | Передача согласованных мастер-данных в системы-потребители |

## Архитектурные модели MDM

| Модель | Принцип | Когда использовать |
| --- | --- | --- |
| Registry | Хранит __идентификаторы и связи__ между записями разных систем | Необходимо объединить клиентов без изменения существующих систем |
| Consolidation | __Собирает данные__, формирует Golden Record, __не обновляет источники__ | Аналитика, DWH, клиентская сегментация |
| Coexistence | Консолидирует данные и __синхронизирует изменения с источниками__ | Несколько систем могут изменять данные |
| Centralized | MDM становится основной системой __создания и изменения мастер-данных__ | Централизованное управление справочниками, продуктами, клиентскими данными |

Для крупного банка обычно целесообразна гибридная модель: например, Coexistence для клиентских данных и Centralized для продуктового каталога.

## Технологии

| Решение | Основная специализация | Развёртывание |
| --- | --- | --- |
| Informatica MDM | Enterprise Multi-domain MDM, Customer 360 | Облако; варианты развёртывания зависят от продукта |
| IBM Master Data Management | Корпоративные мастер-данные, идентификация клиентов | On-premise / Cloud |
| SAP Master Data Governance | Управление мастер-данными в SAP-ландшафте | SAP-ориентированное |
| Reltio | Cloud-native Customer 360, Entity Resolution | SaaS |
| Semarchy xDM | Multi-domain MDM, Data Governance | Cloud / On-premise |
| Ataccama ONE | Data Quality, MDM, Data Governance | Cloud / Hybrid / On-premise |
| Pimcore | Product MDM, PIM, управление каталогами | Self-hosted / Cloud |
| AtroCore | Open-source MDM/PIM | Self-hosted |
