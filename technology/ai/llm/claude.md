# Claude

## Зачем

- семейство больших языковых моделей компании Anthropic

## Модели

[модели](https://habr.com/ru/companies/studyai/articles/1051470/)

### Claude Opus 4.8 AI

- текущий флагман
- контекстное окно до 1 млн токенов
- адаптивное мышление (модель сама решает, сколько «думать» над задачей в зависимости от её сложности)
- режим Dynamic Workflows для координации сотен параллельных подзадач в Claude Code
- Цена — $5 за миллион входных токенов и $25 за миллион выходных
- правильный выбор для сложной аналитики, агентного программирования

### Claude Sonnet 4.6 AI

- оптимальный баланс качества, скорости и цены
- Полноценный контекст в 1 млн токенов, поддержка расширенного мышления
- цена — $3 за миллион входных и $15 за миллион выходных токенов
