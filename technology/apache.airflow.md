# Apache Airflow

## Зачем

Решение для создания, выполнения, мониторинга и [оркестровки](../arch/pattern/system.design/orchestration-choreography.md) потоков операций по обработке данных.
Решение используется в архитектурном стиле [BigData](../arch/style/bigdata.md) для оркестрации.
